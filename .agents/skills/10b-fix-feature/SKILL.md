# Исправление ошибки

Общие правила — в корневом `AGENTS.md`.

1. Сопоставь симптом с затронутым кодом и его вызывающими участками. Запроси логи только если без них причина неясна.
2. Исправь первопричину минимальным изменением. Для локальной правки не загружай архитектурные helpers.
3. Если ошибка в интеграции, проверь соответствующий API-контракт; если в регистрации зависимостей — `core/di/di.dart`.
4. Для исправления UI просмотри влияние на mobile и web по `AGENTS.md`, даже если ошибка сообщена только на одной платформе. Сообщи фактический результат проверки.
