# Проверка API перед размещением

1. Прочитай релевантные routes/schemas, Flutter ApiService/models, env-пример, Dockerfile и entrypoint. Карточки функций и отчёт предыдущего этапа не обязательны.
2. Сверь `/api/v1`, HTTP-методы, параметры, JSON-поля, nullable, пагинацию, Bearer auth и ошибки. Проверь владение пользовательскими данными.
3. Сопоставь настройки запуска: переменные env, порт контейнера/хостинга, CORS, зависимости, Alembic metadata и цепочку миграций, `/health` и `/ready`.
4. Исправь обнаруженные расхождения в рамках задачи. Не запускай полный набор генераторов, analyzer, тесты, Docker и сборки ради отчёта; правила запусков — в `AGENTS.md`.
5. Сообщи только найденные блокеры и выполненные проверки. Таблица всех endpoint и `artifacts/api-timeweb-check.md` нужны только по просьбе пользователя.
6. Статическая сверка не доказывает успешный runtime/deploy. При уже запрошенном деплое продолжай через `skills/timeweb-deploy/SKILL.md`; иначе заверши ответ без изменения облака.
