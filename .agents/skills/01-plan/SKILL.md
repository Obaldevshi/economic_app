# Необязательное планирование

Общие правила — в корневом `AGENTS.md`.

1. Используй текст запроса, предоставленный файл или существующее описание. Не требуй отдельный файл идеи.
2. Отметь, что уже есть в базе, и выдели только недостающие функции. При необходимости опиши связанные экраны, данные и API-операции в одном коротком плане. Для UI-фичи учитывай mobile и web как части одной реализации.
3. Уточняй только поведение, которое нельзя вывести из запроса и без которого нельзя продолжить. Для очевидного CRUD достаточно списка действий.
4. Если пользователь просит сократить MVP, предложи приоритеты; согласованный объём самостоятельно не уменьшай.
5. По умолчанию ответь в сообщении. Если запрошен файл, сохрани один план с нужными разделами, без цепочки брифов, карт и карточек.
6. Когда пользователь уже поручил реализацию, продолжай её после планирования без отдельного подтверждения плана.
