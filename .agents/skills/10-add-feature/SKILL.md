# Реализация

Общие правила, структура и проверки — в корневом `AGENTS.md`.
Любое изменение UI в `init-app`, включая мелкую правку, выполняй сразу для mobile и web по разделу «UI/UX в init-app»; короткий путь сокращает подготовку, но сохраняет обе компоновки.

- **Текст, цвет, отступ, иконка, локальная правка виджета:** открой нужный файл и используемые токены/ARB. Внеси правку напрямую; архитектурные helpers, поиск полного CRUD-примера и чтение backend не нужны.
- **Новый экран или существенная переработка UI:** используй `skills/helper-skill/design-flutter-ui/SKILL.md`; data-слой меняй только если сценарий требует новых данных.
- **Новая API-интеграция или сквозная фича:** прочитай helper только затронутой стороны — `skills/helper-skill/build-flutter-feature/SKILL.md` и/или `skills/helper-skill/build-fastapi-feature/SKILL.md`.

Сохраняй общий клиент/backend контракт. Выполни необходимую генерацию по правилам `AGENTS.md`, затем просмотри diff и подключения. Сообщи результат и продолжи оставшийся согласованный объём.
