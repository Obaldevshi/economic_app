# Ручная проверка по запросу

Общие правила запусков и документов — в корневом `AGENTS.md`.

1. Прочитай изменённый сценарий. Для UI дай несколько шагов на телефоне и в браузере: основное действие, затронутая ошибка, narrow/wide и переход между ширинами. Клавиатуру/touch/мышь включай только для затронутых действий; не расширяй чек-лист на всё приложение.
2. При просьбе дать команды: `flutter run -d <device-id>` для телефона, `flutter run -d chrome --web-port 3000` для web. Сетевые сценарии требуют доступного API из клиентского env.
3. Различай подготовленный чек-лист и выполненную проверку. Если пользователь запросил сам запуск, выполни его в согласованном объёме.
