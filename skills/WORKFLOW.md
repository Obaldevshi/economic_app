# Workflow

Правила структуры, запусков, генерации и документов находятся только в [AGENTS.md](../AGENTS.md). Любое UI/UX-изменение `init-app` включает mobile и web в одной задаче, в том числе при коротком пути для мелкой правки.

```text
Мелкая UI-правка → нужный файл → результат
Новая функция   → $10-add-feature → helper нужной стороны → результат
Ошибка          → $10b-fix-feature → локальное исправление → результат
```

Дополнительные скиллы выбираются по запросу:

- `$01-plan` — единый краткий план: требования, объём, экраны, сценарии и данные.
- `$06-branding` — тема и визуальный стиль.
- `$11-check-feature` — ручной чек-лист.
- `$13-check-api-timeweb` — сверка перед размещением или отдельный аудит API.

Номер скилла не задаёт последовательность. Прямой запрос на реализацию не требует планирования и промежуточной приёмки.

По запросу на размещение прочитай `skills/timeweb-deploy/SKILL.md`, затем инструкции только нужных этапов: API, web или domains. Результат статической сверки и успешный runtime/deploy различай.
