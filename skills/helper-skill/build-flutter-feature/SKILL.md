# Flutter-фича

Структура, общие ограничения и генерация описаны в корневом `AGENTS.md`. Образец — `CategoryRepository` и `CategoryBloc`.

1. Переиспользуй существующие request/response-модели и ApiService; добавь только недостающие поля и методы под контракт backend.
2. Собери операции новой фичи в один конкретный repository. BLoC вызывает его напрямую и хранит response-модели; JSON/HTTP остаются в data-коде.
3. Подключи repository через `registerLazySingleton`, BLoC через `registerFactory` в `lib/core/di/di.dart`. Генерация DI отсутствует; инициализацию сервисов и восстановление сессии сохраняй.
4. Добавь общий маршрут в `app/app_router.dart` и UI в каталог фичи, сразу с mobile/web-компоновкой по `AGENTS.md`. Для нового экрана используй `../design-flutter-ui/SKILL.md`, если он ещё не прочитан.
5. При доработке готовых auth/profile используй их действующий контракт. Они не являются образцом слоёв для новых фич.
